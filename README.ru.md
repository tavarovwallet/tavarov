# Tavarov Pay

Приём платежей в USDT и USDC на BNB Chain — без банка посередине.

Продавец выставляет счёт и получает ссылку с QR-кодом. Покупатель платит,
и деньги идут **из его кошелька прямо в кошелёк продавца**. На нашей стороне
денег нет вообще: ни баланса, ни выплат по расписанию, ни счёта, который
можно заморозить.

Кошелёк некастодиальный: ключи остаются на устройстве, мы до них не
дотягиваемся.

* Витрина: <https://tavarov.com>
* Кошелёк и касса: <https://wallet.tavarov.com>
* In English: [README.md](README.md)

## Честное состояние проекта

Этот раздел стоит первым намеренно. Всё, что здесь написано, любой всё равно
проверит на bscscan за пять минут — лучше узнать это от нас.

* **Независимого аудита у контрактов нет.** Код открыт и сверен с байткодом,
  но «открыт» и «проверен специалистами» — разные вещи. Держите в кассе
  суммы, которые не жалко потерять, пока аудита нет.
* **Настоящих продавцов и покупателей пока нет.** Через контракт в основной
  сети прошли только наши собственные проверочные платежи. Все цифры про
  удобство и скорость — наши ожидания, а не чужой опыт.
* **TVR — это баллы, а не вложение.** У них нет цены, они не торгуются ни на
  одной бирже, и мы не собираемся её устраивать. Больше половины выпуска
  лежит на одном кошельке — нашем. Потратить баллы пока негде: магазин имён
  написан, но не развёрнут.
* **Владелец контрактов — один кошелёк.** Он может менять комиссию (не выше
  2%, это в коде), адрес казны и список принимаемых валют. Он НЕ может
  тронуть выручку продавцов. Отказ от этой власти (`renounceOwnership`) не
  сделан: правила ещё меняются.
* **Комментарии в коде на русском.** Так вышло исторически, и переписать их
  теперь нельзя: подтверждение исходника на bscscan идёт побайтово, и любая
  правка комментария сломает сверку.

## Как всё устроено

```
www/index.html      кошелёк и касса — одно приложение, один файл
www/invoice.html    кабинет продавца: выставить счёт, следить за оплатой
www/pay.html        страница покупателя; сам счёт лежит в адресе после #
functions/api/      единственная серверная часть: «оплачен ли счёт?»
site/               витрина tavarov.com
token/              контракты
i18n/               словари пяти языков и сборка
audit/              проверки в настоящем браузере
```

Счёт **не хранится на сервере**. Он целиком лежит в ссылке, после решётки —
то есть не уходит даже к хостингу. Ответ «оплачено или нет» читается из
блокчейна, а не из нашей базы: базы нет.

Приложение — один HTML-файл без сборки. Открывается с диска, работает без
интернета в той части, где интернет не нужен.

## Запустить у себя

```bash
python3 -m http.server 8099 --directory www
# и открыть http://localhost:8099/index.html
```

Проверки (нужен Node и Playwright):

```bash
cd audit && ./runall31.sh
```

Пути внутри проверок абсолютные — они написаны под нашу машину сборки.
Чтобы прогнать их у себя, поправьте корень в `audit/boot.mjs`.
