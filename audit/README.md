# audit/ — проверки в настоящем браузере

Каждый `tNN-*.mjs` поднимает кошелёк (или функцию сервера) и проверяет одно
дело так, как его делает человек. В GitHub Actions они не запускаются: им
нужен Chromium из Playwright и поддельный узел сети (`mocknode.mjs`).

## Как запустить

```sh
ln -s "$(pwd)" /home/claude/apk        # старые проверки ищут репозиторий там
export NODE_PATH=/path/to/global/node_modules   # где лежит playwright
cd audit && node t65-api-server.mjs
```

Итог печатается последней строкой: `--- 117 из 117 ---`. Проверки,
обновлённые 4 ноября 2026, путь `/home/claude/apk` уже не используют.
