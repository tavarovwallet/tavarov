Meet NoN Wallet
01

Selling? Start with NoN Wallet.

Open NoN Wallet → Payments → Accept payments on a website (API) → Open dashboard. Create your API key there.

02

Connect Tavarov Pay.

Use the key with the WooCommerce plugin, web cashier, or your own checkout.

03

Buying? Choose your wallet.

Pay with NoN Wallet, MetaMask, Trust Wallet, Phantom, or another wallet compatible with the selected network.

Already use MetaMask? The developer dashboard also offers MetaMask sign-in. Customers do not need to install NoN Wallet.

NoN Wallet is a self-custody wallet. Keep your recovery phrase safe: it gives access to your funds. Tavarov Pay is a separate payment service; customers can pay from compatible wallets. Wallet and token support varies by network. Blockchain network fees apply.

Tavarov Pay’s current service fee is 1%. On EVM networks, the contract owner can change it up to 2%. The contracts have not been independently audited.
